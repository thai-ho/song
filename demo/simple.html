🌊 Sóng - Simple Example

Watch the background change as you interact with the album art below!

How to use Sóng:

// 1. Include the script
<script src="song.js"></script>

// 2. Initialize Sóng
const backdrop = Song.create({
    targetElementId: 'my-album'
});

// 3. That's it! The backdrop updates automatically

Advanced Options:

const backdrop = Song.create({
    targetElementId: 'my-album',
    colorCount: 4,           // Number of colors to extract
    waveIntensity: 0.8,      // Wave animation intensity
    animationDuration: 20,   // Animation speed (seconds)
    blurIntensity: 8,        // Backdrop blur amount
    backdropOpacity: 0.7,    // Backdrop opacity
    autoUpdate: true         // Auto-update on changes
});
